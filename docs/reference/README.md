# Reference photos

Real photos from the owner, establishing the visual bar for the whole
project — not a one-phase detail. When in doubt about whether scenery reads
as "beautiful enough" or "real enough," compare against these before
guessing. This library grows over time; check back for new files before
assuming it's complete.

## Toy

- `ball-cord-cuff.jpeg` — the physical tethered-ball toy. Ball material,
  stripe wobble, and the coiled semi-rigid cord in `src/ballView.ts` are
  tuned against this. The cuff (`src/cougar/quadruped.ts`,
  `src/cougar/materials.ts`) is not yet — see the Phase 3 plan's Status
  section. Note the small dark knot at the **cuff end** of the cord too, not
  just where it loops through the ball.

## Water, sky, and mountain (the "breathtaking" bar for the lake + backdrop)

- `lake-sunset.jpeg`, `sky-dramatic-sunset.jpeg` — deep orange/rose/purple
  sunset cloud color and a mirror-still water reflection. Primary target for
  ROADMAP.md's sunset item and for how reflective the lake surface should
  read once it's actually visible.
- `lake-path.jpeg`, `path-deck-lake.jpeg` — the "standing on a bluff/terrace
  looking down at the water through trees" composition ROADMAP.md's lake
  item calls for, including dappled light through tree canopy and a built
  railing/deck edge as a foreground frame.
- `pond.jpeg` — a smaller, darker, forest-shaded water body; useful
  specifically for ROADMAP.md item 4's "second small water feature
  (creek/spring) distinct from the lake," not the main lake.
- `waterfall.jpeg` — Whitewater Falls-style multi-drop cascade in dense
  forest; long-term inspiration, not a near-term build target.

## Garden and living detail

- `daisies-lake.jpeg`, `rhododendron.jpeg`, `knockout-roses.jpeg`,
  `garden-ref.jpeg` — bloom density and layering target for ROADMAP.md item
  3 (garden depth). Note how packed and layered these are — "a single tidy
  row" is explicitly not the bar.
- `deer-roadside-flowers.jpeg` — a real WNC animal cameo living naturally
  among planted flowers next to a road, not deep wilderness. Useful
  reference for how Phase 4's new animal cameos (garter snake, rabbit,
  turtle) should feel integrated into the built garden/path rather than
  placed in an untouched wild area.
